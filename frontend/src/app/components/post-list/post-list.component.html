About this list ▼

Welcome to The Boycott List! I got this idea because I always see and hear about companies that are doing harm to the environment or society. I sometimes forget which companies are on the list and why, so I created this simple tool to keep track of them. I will add the companies as I find them, and you can contribute as well! I provide information about companies that are engaging in unethical practices. I also provide sources of course. Some of the things on this list will be hard to boycott because we might not be able to properly live without them, so for those it will be about raising awareness. Ultimately, this website is mainly for me, to help me stay informed and make conscious choices.
